# Informasi Website UTS

**Nama Website:** Website Profil SMAN 1 Karangkobar

**Framework:** Next.js

**Platform Deployment:** Vercel

**Repository GitHub:** https://github.com/LangeRes/uts-website-sman1-karangkobar

**Alamat Website:** https://uts-website-sman1-karangkobar.vercel.app/

## Deskripsi

Website ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS). Website berisi informasi profil sekolah, sejarah, visi dan misi, serta berita dan kegiatan yang berkaitan dengan SMAN 1 Karangkobar.

Website dikembangkan menggunakan Next.js dan di-deploy melalui Vercel agar dapat diakses secara online.
